# Tokenizer 작업 메모 규칙
- 이 파일은 토크나이저 관련 변경/실험/설정값을 기록하는 전용 메모장입니다.
- 변경/실험을 시작할 때마다 날짜/목적/파라미터(window/stride/Gt/Kt/max_len/struct_offset 등)를 적고, 적용 코드/커밋/체크포인트 경로를 남깁니다.
- KoEn/KoBERT는 현재 비사용(차단) 상태이며, 구조 토크나이저(TCodebook sliding)가 기본이자 유일한 선택지입니다.
- ids→텍스트 복원은 지원하지 않으므로, 구조 토큰 문자열(KA07 등)로만 디버깅합니다. 자연어 대응이 필요하면 원문을 별도 메타로 저장하세요.
- 윈도우/스트라이드가 바뀌면 전체 데이터 재토크나이징이 필요합니다. 설정 불일치 방지를 위해 체크포인트 args와 여기 메모에 동일 값을 기록하세요.
