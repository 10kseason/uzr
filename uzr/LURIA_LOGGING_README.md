# UZR Luria Logging System

UZR 메모리 시스템의 동작을 정량화하고 분석하기 위한 로깅 시스템입니다.

## 📁 디렉토리 구조

구현된 로깅 시스템은 다음과 같은 구조로 되어 있습니다:

```
uzr/
├── utils/
│   └── logger_luria.py          # 공통 로거 유틸
├── hooks/
│   └── stage.py                 # 스테이지 전환 로깅
├── luria_logging/               # ⚠️ 주의: memory가 아닌 luria_logging 디렉토리
│   ├── shadow_bank.py           # Shadow Bank 이벤트 로깅
│   ├── metrics.py               # 메트릭 스냅샷 로깅
│   └── dedup.py                 # 중복 감지 로깅
├── memory.py                    # CompressedMemory 클래스 (get_memory_stats 추가됨)
├── train_meta_3brains.py        # 카운터 및 로깅 통합됨
└── analyze_memory_funnel.py     # 분석 스크립트
```

## 📊 생성되는 로그 파일

훈련 중에 `logus-luria/` 디렉토리에 다음 파일들이 자동 생성됩니다:

```
logus-luria/
├── stage_events.jsonl           # 스테이지 전환 이벤트
├── shadow_bank_events.jsonl     # Shadow Bank 이벤트 (promote/decay/skip 등)
├── shadow_bank_stats.csv        # Shadow Bank 통계 스냅샷 (100 스텝마다)
├── dedup_stats.csv              # 중복 감지 통계
└── session_summary.json         # 세션 종료 시 요약
```

## 🚀 사용법

### 1. 훈련 시작

일반적인 훈련 명령어로 시작하면 자동으로 로깅이 시작됩니다:

```bash
python -m uzr.train_meta_3brains --steps 10000 --save checkpoint.pt
```

### 2. 로그 확인

훈련 중 또는 훈련 후 `logus-luria/` 디렉토리를 확인하여 로그를 분석할 수 있습니다.

#### Shadow Bank 통계 확인
```bash
# CSV 파일 직접 확인
cat logus-luria/shadow_bank_stats.csv

# 또는 pandas로 분석
python -c "import pandas as pd; df = pd.read_csv('logus-luria/shadow_bank_stats.csv'); print(df.tail())"
```

#### 스테이지 이벤트 확인
```bash
# JSONL 파일 확인
cat logus-luria/stage_events.jsonl
```

#### 세션 요약 확인
```bash
cat logus-luria/session_summary.json
```

### 3. 분석 스크립트 실행

분석 스크립트를 실행하여 시각화 및 통계를 생성할 수 있습니다:

```bash
python analyze_memory_funnel.py
```

이 스크립트는 다음을 생성합니다:
- `shadow_dynamics.png`: Shadow Bank 동역학 시각화
- `dedup_stats.png`: 중복 감지 통계 시각화
- 콘솔에 출력되는 통계 요약

## 📈 주요 지표 설명

### Shadow Bank 통계 (shadow_bank_stats.csv)

| 필드 | 설명 |
|------|------|
| `step` | 현재 훈련 스텝 |
| `stage` | 현재 스테이지 (warmup/training/autonomous) |
| `shadow_size` | Shadow Bank의 현재 크기 |
| `shadow_mean_age` | Shadow Bank 항목들의 평균 나이 (스텝) |
| `shadow_age_p95` | 나이의 95번째 백분위수 |
| `shadow_surprise_mean` | Surprise 값의 평균 |
| `shadow_surprise_p75` | Surprise 값의 75번째 백분위수 |
| `promote_ratio` | 승격 비율 (promote / (promote + skip)) |
| `decay_freq` | 현재 스텝의 Decay 빈도 |
| `skip_count` | 현재 스텝의 Skip 횟수 |
| `commit_count` | 현재 스텝의 Commit 횟수 |
| `merge_count` | 현재 스텝의 Merge 횟수 |
| `near_merge_count` | 현재 스텝의 Near Merge 횟수 |
| `mem_size` | 메모리의 현재 크기 |
| `wm_curr` | Working Memory 크기 |
| `recall_topk` | Recall Top-K 값 |

### Stage Events (stage_events.jsonl)

각 이벤트는 다음 형식입니다:
```json
{
  "ts": "2025-10-29T12:34:56.789Z",
  "step": 1000,
  "event": "stage_change",
  "stage": "training",
  "reason": "warmup_complete",
  "meta": {"warmup_steps": 1000}
}
```

### Shadow Bank Events (shadow_bank_events.jsonl)

Shadow Bank의 개별 이벤트를 기록합니다 (promote, decay, skip 등):
```json
{
  "ts": "2025-10-29T12:34:56.789Z",
  "step": 1500,
  "action": "promote",
  "count": 5,
  "stats": {"threshold": 0.75, "shadow_size_before": 100, "shadow_size_after": 95}
}
```

## 🔍 분석 예시

### 1. Shadow Bank 크기 추이 분석
```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('logus-luria/shadow_bank_stats.csv')
plt.plot(df['step'], df['shadow_size'])
plt.xlabel('Step')
plt.ylabel('Shadow Bank Size')
plt.title('Shadow Bank Size Over Time')
plt.show()
```

### 2. Promote 비율 추세
```python
df = pd.read_csv('logus-luria/shadow_bank_stats.csv')
plt.plot(df['step'], df['promote_ratio'])
plt.xlabel('Step')
plt.ylabel('Promote Ratio')
plt.title('Promote Ratio Over Time')
plt.show()
```

### 3. 스테이지별 통계 비교
```python
df = pd.read_csv('logus-luria/shadow_bank_stats.csv')
grouped = df.groupby('stage')[['shadow_size', 'promote_ratio', 'mem_size']].mean()
print(grouped)
```

## 📝 주의사항

1. **디스크 공간**: 장시간 훈련 시 로그 파일이 커질 수 있습니다. 디스크 공간을 주기적으로 확인하세요.
2. **성능 영향**: 로깅은 최소한의 성능 영향을 주도록 설계되었지만, 매우 빈번한 로깅은 훈련 속도에 영향을 줄 수 있습니다.
3. **에러 처리**: 로깅 실패가 훈련을 중단시키지 않도록 try-except로 보호되어 있습니다.

## 🐛 문제 해결

### 로그 파일이 생성되지 않는 경우

1. `logus-luria/` 디렉토리 권한 확인
2. 훈련이 충분히 진행되었는지 확인 (100 스텝 이상)
3. import 에러가 없는지 확인

### 분석 스크립트 실행 오류

필요한 패키지 설치:
```bash
pip install pandas matplotlib
```
